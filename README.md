# Ecommerce-Delivery-Performance-Analysis
E-commerce delivery performance analysis using SQL and Power BI to identify delayed routes, courier performance, and last-mile delivery inefficiencies.

## Project Overview
An end-to-end Data Analytics project using SQL and Power BI to analyze e-commerce delivery performance, identify delayed routes, evaluate courier partner performance, and improve last-mile delivery efficiency in Tier 2 cities.

## Business Problem
Which delivery routes and product categories have consistently late deliveries, and how can last-mile delivery efficiency be improved in Tier 2 cities?

## Tools & Technologies
- SQL
- Microsoft Power BI
- DAX
- Microsoft Excel
- Data Cleaning and Validation
- Exploratory Data Analysis (EDA)

## Project Workflow
1. Business Understanding
2. Data Cleaning and Validation using SQL
3. KPI Calculation
4. Exploratory Data Analysis
5. Business Analysis using SQL
6. Interactive Dashboard Development using Power BI
7. Business Insights and Recommendations

## Key Performance Indicators
- Total Shipments
- On-Time Delivery Rate
- Late Delivery Rate
- Average Delivery Time
- Average Dispatch Time
- Cancellation Rate

## Key Business Questions
1. Which pincodes have the highest late delivery rates?
2. Which courier partner has the best on-time delivery rate?
3. Which product categories experience more delays?
4. Which warehouse has the longest dispatch time?
5. Which routes need last-mile optimization?

## Key Findings
- Overall On-Time Delivery Rate: 65.85%
- Late Delivery Rate: 34.15%
- Madurai recorded the highest city-level late delivery rate.
- Fashion recorded the highest category-level late delivery rate.
- BlueDart achieved the highest on-time delivery rate among analyzed courier partners.

## Business Recommendations
- Optimize high-delay delivery routes.
- Improve courier partner allocation.
- Monitor warehouse dispatch efficiency.
- Investigate repeated delivery delays.
- Improve last-mile delivery planning.
